# Intuition

The goal is to find the median of two sorted arrays. Instead of merging the two arrays completely into a new sorted array (which would take extra space), we can simulate the merge process using a two-pointer approach. Since the arrays are already sorted, we can find the exact middle position(s) by tracking elements sequentially until we reach the median index.

---

# Approach

1. **Calculate Midpoint Targets:** We find the total number of elements `total = nums1.size() + nums2.size()`. The median will lie at index `total / 2`.
2. **Two-Pointer Simulation:** We use two pointers, `i` for `nums1` and `j` for `nums2`, both initialized to `0`.
3. **Track Values:** Because the total number of elements can be even or odd, we maintain two tracking variables: `curr` (the current element) and `prev` (the immediately preceding element).
4. **Iterate to Median:** We loop `target + 1` times. In each iteration:
* We update `prev = curr`.
* We pick the smaller element between `nums1[i]` and `nums2[j]`, advance the corresponding pointer, and assign that value to `curr`. We also ensure proper boundary checks if one array runs out of elements first.


5. **Compute the Median:**
* If `total` is odd, the median is simply `curr`.
* If `total` is even, the median is the average of `prev` and `curr`, calculated as `(prev + curr) / 2.0`.



---

# Complexity

* **Time complexity:** $O(m + n)$
Where $m$ and $n$ represent the lengths of `nums1` and `nums2` respectively. The loop runs exactly $\lfloor (m + n) / 2 \rfloor + 1$ times to reach the median element(s).
* **Space complexity:** $O(1)$
The algorithm only tracks a few primitive variables (`i`, `j`, `prev`, `curr`, etc.) to traverse the arrays, requiring constant extra memory.

---

# Code

```cpp []
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        int total = nums1.size() + nums2.size();
        int target = total / 2;
        int i = 0, j = 0;
        int prev = 0, curr = 0;
        
        for (int k = 0; k <= target; k++) {
            prev = curr;
            if (j >= nums2.size() ||
                (i < nums1.size() && nums1[i] <= nums2[j])) {
                curr = nums1[i++];
            } else {
                curr = nums2[j++];
            }
        }
        
        if (total % 2 == 1) {
            return curr;
        }
        return (prev + curr) / 2.0;
    }
};

```
