# Intuition

To find the longest substring without repeating characters, we can imagine a window sliding across the string. If we come across a character that we've already seen in our current window, our window becomes invalid. Instead of resetting completely and starting over from the next character, we can efficiently shrink our window from the left until the repeating character is removed, and then keep expanding to the right.

# Approach

1. **Initialize a Frequency Array:** We use a vector `freq` of size 256 (initialized to 0) to keep track of the count of characters within our current window. This acts as a highly efficient hash map for ASCII characters.
2. **Setup Two Pointers:** We use `left` and `right` pointers to represent the boundaries of our sliding window. Both start at index 0. We also maintain a variable `ans` to store the maximum length found so far.
3. **Expand the Window (`right` pointer):** We iterate through the string using the `right` pointer. Before adding `s[right]` to our window, we check if it already exists (`freq[s[right]] > 0`).
4. **Shrink the Window (`left` pointer):** If the character at `right` is a duplicate, we enter a `while` loop to shrink the window from the left. We decrement the frequency of `s[left]` and increment `left` until the duplicate character is excluded from our window.
5. **Update and Record:** Once the window is guaranteed to have unique characters, we increment the frequency of `s[right]` and update our maximum length `ans` using `max(ans, right - left + 1)`.

# Complexity

* **Time complexity:** $O(n)$
Although there is a nested `while` loop, each character is visited at most twice: once by the `right` pointer expanding the window, and at most once by the `left` pointer shrinking it. Thus, the total operations are linear relative to the length of the string $n$.
* **Space complexity:** $O(1)$
The space complexity is constant because the `freq` vector is fixed at a size of 256, regardless of how large the input string $n$ becomes.

# Code

```cpp []
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> freq(256, 0);
        int left = 0;
        int ans = 0;
        for (int right = 0; right < s.size(); right++) {
            while (freq[s[right]] > 0) {
                freq[s[left]]--;
                left++;
            }
            freq[s[right]]++;
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```
